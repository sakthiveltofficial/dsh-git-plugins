# @dsh-git/azuredevops

Azure DevOps adapter for `gitPlatform`: pull requests, builds, and work items (issues) over the REST API. Releases and security alerts are unsupported (`GIT_UNSUPPORTED`).

Part of the [dsh-git](https://github.com/sakthiveltofficial/dsh-git-plugins) plugin suite for DeepSeek Harness — see the root README for install and usage.
