# @dsh-git/tool-git

The model-facing tool layer: `git_repo`, `git_inspect`, `git_pr`, `git_issues`, `git_release`, `git_security`, and `git_ci` — grouped, typed, policy-aware git tools over `gitLocal` and `gitPlatform`.

Part of the [dsh-git](https://github.com/sakthiveltofficial/dsh-git-plugins) plugin suite for DeepSeek Harness — see the root README for install and usage.
