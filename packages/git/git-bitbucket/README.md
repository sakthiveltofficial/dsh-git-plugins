# @dsh-git/bitbucket

Bitbucket (Cloud) adapter for `gitPlatform`: pull requests, issues, and Pipelines over REST 2.0. Releases map to tags; security alerts are unsupported (`GIT_UNSUPPORTED`).

Part of the [dsh-git](https://github.com/sakthiveltofficial/dsh-git-plugins) plugin suite for DeepSeek Harness — see the root README for install and usage.
