# @dsh-git/core

Service Definitions and vocabulary for the Git capability seam: the abstract `gitLocal` (plumbing/porcelain) and `gitPlatform` (hosted-platform registry) services, the shared `GitError` taxonomy, remote-URL parsing, and HTTP plumbing.

Part of the [dsh-git](https://github.com/sakthiveltofficial/dsh-git-plugins) plugin suite for DeepSeek Harness — see the root README for install and usage.
