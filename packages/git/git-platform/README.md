# @dsh-git/platform

The `gitPlatform` registry/dispatcher: one service, many hosted-platform adapters. Detects the host from a repo's origin remote URL, applies rate-limit backoff, and caches reads.

Part of the [dsh-git](https://github.com/sakthiveltofficial/dsh-git-plugins) plugin suite for DeepSeek Harness — see the root README for install and usage.
